# Eid Gift

A cute interactive Eid card for Nivita, built with React, Vite, Tailwind CSS, Framer Motion, and canvas-confetti.

## Local commands

```bash
npm install
npm run dev
npm run build
```

## Deployment

This repo includes a GitHub Pages workflow. After pushing to `main`, enable GitHub Pages with **GitHub Actions** as the source if it is not already enabled.
